# Profile Pal

Profile Pal is a macOS app for building and editing Apple configuration profiles (`.mobileconfig`). Its editor is driven by [ProfileManifests](https://github.com/ProfileManifests/ProfileManifests), which describe each payload and its settings.

## Motivation

Existing profile tools tend to assume Mac admin experience. Profile Pal aims to be approachable for people without that background, while also fitting my own needs and workflows better than the alternatives.
